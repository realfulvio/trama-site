What goes in and what comes out

Pick a format to see its path and what it keeps.

Trama reads

  • .alabTrama projectData, formulas, exclusions, analysis recipes, styles, layouts, Info sheets and links between analyses.
  • .csvDelimited textImports tables with a filtered preview; exports result tables.
  • .tsv · .txtTab-separated textImport with preview, choice of separator and rows.
  • .xlsxWorkbookImports sheets as data; workbook formulas do not become recipes.
  • XML · ZIPXML and ZIP projects from commercial softwareTables and metadata, supported recipes (including hierarchical clustering), archived results and saved XY coordinates. Partial import.
  • binaryBinary projects and templates from commercial softwareTables, archived results, original PDF/EMF views; some XY and column graphs become editable. Partial import.
  • .txtInfo sheet notesConstants and notes as UTF-8 text.
  • More layouts and graph types from binary projects
  • More encodings and exclusions in imported files
  • Live links to source files
  • Value-based filters on import

Trama writes

  • .alabTrama projectData, formulas, exclusions, analysis recipes, styles, layouts, Info sheets and links between analyses.
  • .csvDelimited textImports tables with a filtered preview; exports result tables.
  • .pngPNG imageRaster figures and layouts at a chosen size and resolution.
  • .tif · .tiffTIFF imageRaster for print and journals.
  • .svgSVG vectorText and shapes stay vector in native graphs and layouts.
  • .pdfPDFFigures, layouts and multi-page PDFs with several sheets in one file.
  • .emfEMF metafileExports an imported layout after editing it.
  • .txtInfo sheet notesConstants and notes as UTF-8 text.
  • Full round trip with external projects

Dashed squares are development goals, not release dates, and the number of squares is not a completion percentage: the project does not state a verified overall progress. Third-party formats are imported only for verified content; always keep the original. The list is taken from the code of Trama 0.82.0; version 0.82.0 passed 2,521 tests on Linux and 2,520 on Windows (one symbolic-link check unavailable), which document particular cases and are not a certification. Per-method details are in the features guide (Italian) and the technical inventory.
