Trama 0.113.0 beta Latest version

  • Row order. Reverse the whole worksheet from Edit. Use the row header menu to move selected rows to the top or bottom. Formatting and exclusions follow their rows. Undo restores the previous order.
  • Linked recalculations. Short calculations start immediately. Longer requests start worker processes in the background. Subsequent requests use the workers that are ready.
  • Correlations and graphs. Pearson and Spearman matrices reuse calculations for each column. Graph and layout sheets render at their actual page size.
  • Startup. The splash screen appears while the scientific libraries load. Numerical computations use one BLAS thread per process. Some results on large worksheets can differ in their last digits because of rounding.
Release notes and download

Trama 0.112.0 beta

  • Start screen. Options and preview appear side by side in wide windows. Recent projects open in one click, with open and recovery commands next to the list.
  • Linked data. Link a worksheet to a CSV or TSV during import. File → Update from file… previews changes, asks how to handle conflicts and supports Undo. The project keeps the last confirmed data and opens without the source file.
  • Passing–Bablok regression. Compare two measurement methods with slope, intercept, analytical intervals when estimable and an optional identity line.
  • Rank-test plots. Mann–Whitney and Wilcoxon can produce rank or paired-difference plots.
  • Calculated columns. Formulas follow renamed source columns, including references in a chain of formulas.
  • K-means iterations. The optional report shows the number of iterations and why the algorithm stopped when that information is available.
  • Faster calculations. Automatic Mann–Whitney and Wilcoxon switch earlier to the approximation when the exact test exceeds its budget. Cox regression, XY point worksheets and preparation for multifactor ANOVA are also faster.
  • Dunnett and equations. Supported comparisons against one common control use more accurate quadrature. Adjusted p-values and intervals may change. Custom equations support asin, acos, atan, sinh, cosh and tanh.
Release notes and download

Trama 0.111.0 beta

  • Result formatting. Set significant digits and p-value presentation in Options for multifactor ANOVA, standard t-tests, nonlinear regression and Kaplan–Meier. Tables can show fixed decimals, significance stars or both.
  • Compatible projects. Imported recipes for supported methods restore significant digits and the p value with stars style when saved in the file.
  • Printing and data. Printing uses the displayed format. Copy, data export and calculations continue to use numeric results.
Release notes and download

Trama 0.110.0 beta

  • Paired t-test. In Options, choose a differences plot, a correlation plot or both. You can also keep the estimation plot. The Paired differences sheet identifies each subject and gives the first measurement minus the second. The plots use the complete pairs included in the test.
  • Text toolbar. The font-size field displays all digits and the unit, including for decimal sizes.
Release notes and download

Trama 0.109.1 beta

  • Info sheets. An Info-only project opens to its first sheet or the saved active sheet, where available. If an imported note is unreadable, Trama keeps the sheet fields and identifies the omitted note.
  • Worksheet formulas. The <> comparison works in formulas and in grouped statistic filters on the portable Windows build.
Release notes and download

Trama 0.109.0 beta

  • Command search. Press Ctrl+K to search by command name, menu, or shortcut. The list shows where each command lives and whether it is available in the active view. Use the arrow keys and Enter to run the selected command.
  • Italian results. Descriptive statistics, linear regression, and box and violin plots show Italian results tab labels in the Italian interface. Box and violin plots also show translated column headers. Projects, links, and copied data retain their original names.
Release notes and download

Trama 0.108.0 beta

  • Classic Qt toolbar. Hover over a button to see its command. Choose a font and set its size in pixels or points from the Text group. The cell editor accommodates large type in short rows.
  • Sort worksheet rows. Use Edit → Sort rows to choose a source column and direction. Missing values stay last. Row heights, formats, and exclusions follow their data.
  • Observation labels. Label scatter and XY markers with row titles or values from a worksheet column. Labels are included in exported graphs and layouts.
  • Paired Deming comparison. Compare slopes and intercepts from two Y series with a shared X using their common complete rows. The results include differences and approximate jackknife intervals.
Release notes and download

Trama 0.107.0 beta

  • Rows and numeric series. Drag row headers to reorder rows and drag their edges to resize them. Create numeric series fills a range with an arithmetic or geometric progression.
  • Text formatting. The Text group controls cell font, size, color, alignment and style. Formatting follows cells when rows are reordered. The annotation editor also supports superscripts and subscripts.
  • Tables in graphs and layouts. Insert a selection as a linked table that follows recalculation or as a snapshot of the current values. Text and rules remain vector elements in PDF and SVG.
  • Two-way ANOVA from summaries. Analyze two crossed factors and their interaction using the mean, standard deviation or standard error, and sample size for each cell.
Release notes and download

Trama 0.106.0 beta

  • The welcome page makes blank tables and examples explicit and offers recent projects, recovery and a quick guide. The Graph Inspector can format the color, symbol and size of one observation in supported XY and scatter plots. Styles follow the original worksheet row and are suspended when the association is uncertain. Multifactor ANOVA can report estimated marginal means with standard errors, residual degrees of freedom and confidence intervals. It uses the existing fit and weights each reference-grid cell equally.
Release notes and download

Trama 0.105.0 beta

  • The navigator can duplicate, rename, delete, reorder, highlight and freeze sheets. Frozen analyses keep their confirmed results and graph together. Each sheet can carry formatted notes in a floating window. Category Order can rename and merge levels after checking dependent recipes. Graph drawings can be grouped and locked. Layouts support uniform panel sizes and axis alignment. The View menu fits a graph or page, and the Change menu converts compatible native graphs in place. The File menu includes printing, preview, page setup and figure handoff to locally installed Word or PowerPoint. Ctrl+N creates a project, Ctrl+T creates a table, Ctrl+P prints and Ctrl+Shift+P opens analysis parameters.
Release notes and download

Trama 0.104.0 beta

  • The portable opens in Classic Qt with Trama.exe. The worksheet can show its linked graph and format inspector. Duplicate Family can clear selected values and titles while keeping the recipes. Variable Properties edits worksheet names and types and keeps declared types from supported imports. The menus now offer result copying, column deletion, and project switching.
